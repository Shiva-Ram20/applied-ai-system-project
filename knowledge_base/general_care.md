# General Care Guidelines

## Grooming
Long-haired breeds should have a grooming/brushing task at least 2-3 times
a week; short-haired breeds can usually go once a week. Nail trims are
typically needed every 3-4 weeks.

## Scheduling Priority
Medication and health-related tasks (category "meds") should generally be
marked high priority, since missing them has the most serious consequences.
Enrichment and grooming tasks can usually be medium or low priority.

## Conflict Handling
When two tasks are scheduled at overlapping times, prefer keeping the
higher-priority task at its original time and move the lower-priority task
to start immediately after the higher-priority task ends.

## Recurring Tasks
Daily tasks (like feeding or medication) and weekly tasks (like a grooming
session) should be set up with `recurrence` so they roll forward
automatically instead of needing to be re-added by hand each day/week.

## Multi-Pet Households
When scheduling for a household with multiple pets, check each pet's tasks
against the full household schedule (not just that pet's own tasks) before
confirming times, since one pet's task can still conflict with another
pet's task if they're scheduled by the same person at the same time.
